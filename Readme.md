# Starfield Modding/Creations/SFCK Notes

This site is a collection of multiple people's work and dedication, and is meant to help new and aspiring mod authors develop new mods and creations for Starfield.

## Tools

- VS Code
  - Open source editor from Microsoft
  - [Get from Microsoft](https://code.visualstudio.com/download)
- xEdit 4.1.5q
  - Thank you so much Elminster and the xEdit Team for your hard work and dedication.
  - Only use the version from their Discord
- nifskope
  - Allows texture swaps and modifications for in-game models and assets
  - Only available from the FO76utils fork: [FO76Utils Nifskope](https://github.com/fo76utils/nifskope)
- ce2utils
  - A collection of tools for accessing Starfield data
  - Only available from the FO76utils GitHub repo: [FO76Utils CE2 Utilities](https://github.com/fo76utils/ce2utils)
